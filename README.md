# 短视频分发运营顾问（JX）

内容做好之后，把它安全地发出去。懂视频号与小红书的平台规则和风控边界，
帮你定系列内容的排期节奏、原创声明策略与安全发布方案。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **发布排期设计**：把一批成品视频排成安全、可持续的日更节奏，处理 14 天定时窗口、
  滚动分批、错峰、合集归类等实际问题
- **平台规则判断**：判断某个动作现在还能不能做——能不能补原创、能不能改时间、
  什么时候彻底没机会了（附视频号 / 小红书硬约束速查表）
- **风控边界判断**：判断批量脚本操作会不会被判定为「AI 托管运营」，给出保守替代方案
  （实测结论：脚本进草稿 + 真人手动发布是安全路径）
- **重发决策**：删旧重发会清零播放和赞，值不值得按数据量级给你算清楚
- **执行落地**：内置 `channels-video-publish` 技能，方案定了一键执行，执行后自动复核

## 使用示例

- 「我有 10 条已经做好的视频要发视频号，帮我排一下发布节奏，顺便说说有什么坑」
- 「已发布的内容里有几条忘了声明原创，要不要删了重发？」
- 「用脚本批量定时发布，会不会被平台判定成 AI 托管运营？」

## 内置技能

`channels-video-publish`（视频号自动发布）：上传、填标题描述、归合集、声明原创、
定时发表、改期、全量对账，一条命令完成。

## 安装

将专家包目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/shortvideo-distribution-consultant/
```

然后运行注册命令使其可见：

```bash
python3 <expert-manager>/scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 <expert-manager>/scripts/package_expert.py <expert-dir> [output-dir]
```
